<h1 align="right">Checkpoint 8 – Reflection</h1>

Throughout this mission, **Amazon Web Services (AWS)** stood out as the most impressive platform due to its extensive ecosystem of cloud services spanning compute, storage, databases, networking, and security. Core services like Amazon EC2, Amazon S3, and Amazon RDS effectively support diverse organizational needs and software architectures.

Major public cloud providers—AWS, Azure, and Google Cloud Platform (GCP)—share fundamental architectural capabilities. Each platform delivers virtual machines, object storage solutions, managed databases, identity and access management (IAM), and managed Kubernetes environments. They enable organizations to provision elastic, highly available infrastructure without managing physical hardware assets. While vendor-specific naming conventions and feature sets differ, all three solve core enterprise cloud requirements.

Aligning cloud selection with specific business requirements is critical. Organizations heavily invested in Microsoft enterprise tools often gain greater efficiency with Azure, whereas machine learning initiatives benefit from GCP's specialized AI suite. Early-stage startups typically prioritize cost optimization and rapid scaling, while mature enterprises focus heavily on compliance, robust security controls, multi-region reliability, and peak performance.

Serving in the role of a Cloud Solutions Consultant emphasized that cloud selection extends beyond market popularity. It requires evaluating specific organizational constraints and aligning them with appropriate technical capabilities. This hands-on analysis provided a clear framework for evaluating AWS, Azure, and GCP based on performance and suitability.

This exercise enhanced my GitHub Cloud Computing Portfolio by establishing structured documentation across hands-on activities, service comparisons, client recommendations, decision matrices, and Linux server investigations. Utilizing GitHub as a technical showcase reinforced best practices in documentation management while connecting theoretical cloud computing principles directly to real-world business scenarios.
