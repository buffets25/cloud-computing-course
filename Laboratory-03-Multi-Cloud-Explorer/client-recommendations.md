
# Cloud Platform Recommendations

---

### Client A – Startup Company

**Recommended Platform:** Amazon Web Services (AWS)

AWS is an ideal solution for emerging startups due to its vast library of expandable services that accommodate growing application demands. The business can begin with minimal resource allocation and scale up seamlessly as user adoption expands, minimizing the need to invest in physical server infrastructure.

**Three key services:**

* **Amazon EC2** – Hosts the mobile application's backend architecture.
* **Amazon S3** – Manages object storage for media files and assets.
* **AWS Lambda** – Executes application logic in a serverless environment without managing underlying servers.

---

### Client B – University

**Recommended Platform:** Microsoft Azure

Microsoft Azure represents the most suitable environment because the institution relies on Windows Server, Microsoft 365, and Active Directory. Azure delivers native integration with Microsoft's product suite, simplifying migration pathways and account provisioning while allowing staff to use familiar management tools.

**Three key services:**

* **Azure Virtual Machines** – Runs virtualized Windows Server environments.
* **Microsoft Entra ID** – Handles directory management, single sign-on, and access control.
* **Azure Storage** – Provides centralized file storage and disaster recovery backups.

---

### Client C – AI Research Company

**Recommended Platform:** Google Cloud Platform (GCP)

Google Cloud offers a powerful ecosystem specialized for advanced AI and Machine Learning research. It delivers high-throughput computing power paired with dedicated machine learning frameworks, streamlining the end-to-end development, training, and deployment of intelligent applications.

**Three key services:**

* **Google Compute Engine** – Delivers raw, high-performance compute instances for intensive workloads.
* **Google Kubernetes Engine (GKE)** – Orchestrates containerized machine learning services.
* **Vertex AI** – Offers an end-to-end platform for building, training, and deploying custom AI models.

---

### Client D – Global E-Commerce Company

**Recommended Platform:** Amazon Web Services (AWS)

AWS is well-suited for enterprise e-commerce platforms requiring worldwide presence and geographic redundancy. Its automated scaling capabilities handle high-volume traffic spikes seamlessly, ensuring low latency and consistent application access for international customers.

**Three key services:**

* **Amazon EC2** – Powers core web applications and storefront services.
* **Amazon S3** – Stores product catalog images and digital media assets.
* **Elastic Load Balancing (ELB)** – Distributes incoming user traffic evenly across multiple server instances.

---

## Checkpoint 6 – Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
| :--- | :--- | :--- |
| **Startup Company** | AWS | AWS provides a rich ecosystem of elastic services and pay-as-you-go pricing model, allowing startups to control operational costs while scaling. Core offerings like EC2, S3, and Lambda enable agile application development. |
| **Enterprise Organization** | AWS | AWS delivers robust, enterprise-grade cloud architecture, stringent security controls, and extensive global infrastructure. Services like EC2, RDS, and VPC support complex, high-availability deployments. |
| **Microsoft Environment** | Azure | Azure integrates seamlessly with existing Microsoft enterprise infrastructure. It provides native interoperability with Windows Server, Microsoft 365, Active Directory, and associated identity tools. |
| **AI / Machine Learning** | GCP | GCP stands out for artificial intelligence and data science through specialized tools like Vertex AI, BigQuery, and Google Cloud Storage, simplifying large-scale data analytics and model training. |
| **Kubernetes Deployment** | GCP | GCP features Google Kubernetes Engine (GKE), a industry-leading managed Kubernetes service optimized for deploying, automating, and managing containerized application workloads at scale. |
| **Global Web Application** | AWS | AWS offers superior global reach via its widespread infrastructure and edge locations. Combining EC2, CloudFront, and Route 53 delivers fast, scalable, and resilient web delivery worldwide. |
