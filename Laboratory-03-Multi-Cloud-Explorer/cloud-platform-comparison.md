### Questions

**1. Which cloud provider offers the broadest range of services?**

AWS leads the cloud market with the most comprehensive portfolio, offering well over 200 fully featured services covering computing, scalable storage, managed databases, networking, machine learning, and advanced security.

**2. Which provider best integrates with Microsoft technologies?**

Microsoft Azure provides the most seamless compatibility with Microsoft products, offering deep out-of-the-box integration with Windows Server environments, Microsoft 365, Active Directory, and GitHub.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**

Google Cloud Platform excels in AI, machine learning, and container management. Since Google originally created Kubernetes, GCP delivers a top-tier environment with Google Kubernetes Engine (GKE) alongside robust Vertex AI capabilities.

**4. Which cloud platform would you personally choose and why?**

I would choose **AWS** because of its dominant market share and mature infrastructure. Learning AWS provides hands-on exposure to a wide variety of industry-standard cloud architecture tools, which is highly beneficial for practical development and long-term career growth.
